## 2. Headers HTTP

| Header | Status | Valor configurado |
|---|---|---|
| Content-Security-Policy | ✅ NONCE (proxy.ts) | Gerado por request em `src/proxy.ts`; sem `unsafe-inline`/`unsafe-eval` em script-src |
| Strict-Transport-Security | ✅ | `max-age=63072000; includeSubDomains; preload` |
| X-Frame-Options | ✅ | `SAMEORIGIN` |
| X-Content-Type-Options | ✅ | `nosniff` |
| Referrer-Policy | ✅ | `strict-origin-when-cross-origin` |
| Permissions-Policy | ✅ | `camera=(self), geolocation=(self), microphone=()` |

> **CSP por nonce:** `src/proxy.ts` gera um nonce criptográfico (`crypto.getRandomValues`) por request e injeta `nonce-{value}` em `script-src`. O header CSP estático foi removido do `next.config.ts` para evitar override.
